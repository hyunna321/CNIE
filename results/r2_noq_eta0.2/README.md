# 제안 모델: R2 보상 (큐 항 제외, η 0.2) — `rsv_r2_ord_eta0.2_noq_bat`

M14 K3 λ320, 배터리 on, 로봇별 큐(예약), 학습 시드 1~5, 테스트 시드 10000~10019 (20개).
ablation(`results/r2_ablation`)에서 큐 항을 제외하고, 계수 민감도(`results/r2_sens`)에서 η 0.2, w_ext 1을 선택.
학습: `bash experiments/scripts/run_r2_ablation.sh` (9965WX). 최고 네트워크는 학습 시드 4 → `weights/agent_s4_best.pt`.

## 보상

결정 k (토트 하나를 로봇에 배정하거나 운행 중 로봇의 다음 트립에 예약):

    c_k = inc_k + 0.2 · (T_k^done − t_k) + 1 · (E_k − X_k)
    r_k = −(c_k − μ(λ)) / Z,   μ(320/hr) = 128.4 s (mu_order_ext_eta0.2_wext1_wq0_rsv.json),   Z = 1000

- inc_k: 결정 k가 배정한 토트가 그 주문의 흐름시간을 늘린 양. 주문의 토트를 처리 순서로 놓고
  F_j = max_{i≤j} T_i^done − a_o, inc_j = F_j − F_{j−1}
- T_k^done − t_k: 그 토트의 결정부터 처리 완료까지 시간 (자기 지연)
- E_k: 이 배정이 다른 주문의 계획 완료시각을 늦춘 양, X_k: 다른 결정이 내 주문에 낸 E 중 k로 이전된 몫. Σ_k (E_k − X_k) = 0
- 큐 항 제외 (w_q = 0): 후보 로봇이 없어 FIFO 대기 큐로 간 토트(평가 시 토트의 약 15 %)의 inc는 어떤 결정의 비용에도 넣지 않음
- 에피소드 합: Σ_k c_k = Σ_{결정 토트} inc + 0.2 · Σ_{결정 토트} 체류시간
- 할인 e^{−βτ} (β = 1/10800, 약 3시간), 3-step TD, ring buffer + online 업데이트
