# R2 보상 (rsv_r2_ord_eta0.2_bat)

M14 K3 λ320, 배터리 on, 로봇별 큐(예약), 1000 에피소드, 학습 시드 1~3, 테스트 시드 10000~10019 (20개).
실행: `bash experiments/scripts/run_r2_eta.sh`, 보상 정의: `env/rl.py` OrderExtReward (모듈 설명 "order_ext").

결정 비용 c_k = 자기 토트의 주문 흐름 증분 + 큐 토트 증분 + 0.2 · 자기 토트 체류 + (다른 주문에 낸 외부비용 − 이전받은 몫).
에피소드 합은 Σ 주문 흐름시간 + 0.2 · Σ 토트 체류시간. 학습 설정은 A0 + ring + online(`rsv_local_h3_ro_bat`)과 같고 보상만 다름.

| 정책 | Flow (s) | p99 (s) | Dist (m) | Wait (s) | Totes/trip | BL6R 대비 ΔFlow |
|---|---|---|---|---|---|---|
| BL6R | 218.8 | 406 | 103.3 | 5.60 | 3.49 | — |
| A0 + ring + online (results/step1_ro) | 227.8 | 440 | 103.0 | 6.89 | 3.80 | +9.1 |
| R2 eta0.2, 학습 시드 1~3 평균 | 225.0 | 414 | 103.4 | 7.36 | 3.82 | +6.2 (se 4.4, 학습 시드 단위) |
| R2 eta0.2, 학습 시드 1 | 218.5 | 412 | 103.1 | 5.73 | 3.61 | −0.3 ± 0.4 (테스트 시나리오 단위) |

- 학습 시드별 Flow 218.5 / 223.2 / 233.4 (검증 선택 에피소드 400 / 250 / 300). 시드 간 편차(std 7.6)가 커서 학습 시드 단위로는 BL6R·A0와 차이가 유의하지 않음
- 시드 1 네트워크는 BL6R과 같은 수준 (테스트 시나리오 20개 대응 차이 −0.3 ± 0.4 s)

파일
- `test_summary.csv`: 정책별 평균. `se` = 테스트 시나리오 20개 대응 차이의 표준오차, `se_train_seed` = 학습 시드 단위 표준오차, `seed_flows` = 학습 시드별 네트워크 평균 흐름
- `eval_s1.csv`: 학습 시드 1 네트워크의 테스트 시나리오별 결과와 같은 시나리오의 BL6R 흐름 (`bl6r_flow`)
