# R4 가중치 (rsv_r4_wext2_bat, rsv_r4_wext3_bat)

M14 K3 λ320, 배터리 on, 로봇별 큐(예약), 1000 에피소드, 학습 시드 1~3, 테스트 시드 10000~10019 (20개).
실행: `bash experiments/scripts/run_r4_wext.sh`, 보상: `env/rl.py` LocalReward (모듈 설명 "local").

A0 local 보상 식은 그대로 두고 탑재 토트 지연 계수 w_ext만 바꿈 (새 항 없음).
c_k = 자기 토트 체류 + w_ext · (이 결정으로 이미 탑재·예약된 토트가 늦어지는 시간 추정) + w_q · 큐잉 토트 지연.
새 출발(쉬는 로봇)은 탑재 토트가 없어 2항이 0이므로, w_ext는 운행 중 트립에 얹는 결정의 단가.
가설: w_ext ↑ → 얹기 ↓, Totes/trip ↓ → 트립 내 지연 ↓ → Flow ↓.

| 정책 | w_ext | Flow (s) | p99 (s) | Dist (m) | Wait (s) | Totes/trip | 필수 충전 | BL6R 대비 ΔFlow (학습 시드 se) |
|---|---|---|---|---|---|---|---|---|
| BL6R | — | 218.8 | 406 | 103.3 | 5.60 | 3.49 | 0.10 | — |
| A0 + ring + online (results/step1_ro) | 1 | 227.8 | 440 | 103.0 | 6.89 | 3.80 | 0.10 | +9.1 |
| R4 w_ext 2 | 2 | 227.4 | 451 | 103.7 | 6.85 | 3.75 | 0.05 | +8.6 (0.9) |
| R4 w_ext 3 | 3 | 226.5 | 528 | 105.1 | 10.34 | 3.52 | 0.87 | +7.7 (2.4) |

- 학습 시드별 Flow: w_ext 2 228.6 / 227.9 / 225.7 (검증 선택 에피소드 150 / 900 / 300), w_ext 3 229.8 / 227.7 / 221.9 (100 / 250 / 450)
- w_ext를 올리면 Totes/trip은 3.80 → 3.75 → 3.52로 BL6R(3.49) 수준까지 내려가지만 Flow는 A0와 같은 수준 (−0.4, −1.4 s)
- 대신 w_ext 3에서 Wait +3.4 s, p99 +88 s, Dist +2 m, 필수 충전 증가: 새 출발에 쓴 로봇만큼 쉬는 로봇이 줄어 다음 주문이 기다림
- 해석: w_ext는 "얹기 대 새 출발"의 고정 환율이라 얹는 평균 수준만 옮기고 상태별 판단은 바꾸지 못함. 손해가 트립 내 지연에서 대기로 옮겨 감

파일
- `test_summary.csv`: 정책별 평균. `se` = 테스트 시나리오 20개 대응 차이의 표준오차, `se_train_seed` = 학습 시드 단위 표준오차, `seed_flows` = 학습 시드별 네트워크 평균 흐름, `selected_episode` = 검증으로 고른 체크포인트
- `eval_wext2.csv`, `eval_wext3.csv`: 학습 시드 3개 × 테스트 시나리오 20개 결과와 같은 시나리오의 BL6R 흐름 (`bl6r_flow`)
