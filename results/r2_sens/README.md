# R2 −queue 보상 계수 민감도 (rsv_r2_noq_*_bat)

기준: `rsv_r2_ord_eta0.2_noq_bat` (w_ext 1, w_q 0, η 0.2, 학습 시드 1~5는 `results/r2_ablation`). 계수 하나만 바꿈.
M14 K3 λ320, 배터리 on, 로봇별 큐(예약), 1000 에피소드, 학습 시드 1~5, 테스트 시드 10000~10019 (20개).
실행: `bash experiments/scripts/run_r2_sens.sh` (9965WX, 35개 동시, 약 17.5시간 + μ 약 5시간).

결정 비용 c_k = inc + η · 자기 지연 + w_ext · (E − X)  (w_q = 0)

## 구간 설정 근거 (BL6R prior, M14 λ320, 테스트 시드 10000 한 에피소드)

| 항 | 결정당 평균 | 결정 간 std |
|---|---|---|
| inc | 93.6 s | 113.3 |
| 자기 지연 (계수 전) | 219.6 s | 83.8 |
| E − X | 0 (합 0) | 49.5 |

- η ∈ {0, 0.1, 0.2, 0.5, 1}: η · 자기 지연이 결정 비용에서 차지하는 비율 0, 19, 32, 54, 70 % (η ≈ 0.43에서 inc와 같음). η는 에피소드 목표 자체를 바꿈 (Σ 흐름 + η Σ 토트 체류)
- w_ext ∈ {0, 0.5, 1, 2}: 외부비용 항 std가 inc std의 0, 0.22, 0.44, 0.87배. Σ(E − X) = 0이라 목표는 같고 결정별 책임 배분만 바뀜

## 해석

- η: 0~1 전 구간에서 기준과 유의한 차이 없음 (모든 |Δ| ≤ 1 se). η = 1(체류 항 70 %)에서도 Totes/trip, Dist가 그대로 → 학습된 정책이 보상 목표 변화에 거의 반응하지 않음. η가 클수록 후반 검증 Flow 평균이 나빠짐 (323 → 483 s), 선택 체크포인트는 비슷
- w_ext: 기준 1이 가장 좋고 양쪽으로 나빠지는 모양 (0: +6.7, 0.5: +5.0, 2: +8.6 ± 3.6 ≈ 2.4 se). w_ext = 0은 시드 std 13.1로 가장 불안정 → 외부비용 이전이 학습 안정성에 기여한다는 약한 근거, w_ext = 1 선택 근거
- 모든 설정에서 후반 검증 Flow가 300~480 s로 진동 (BL6R ≈ 219) → 학습 불안정은 계수와 무관하게 남아 있음. 40개 네트워크 중 12개는 검증 선택 에피소드가 250 이하 (prior에 가까운 초기 체크포인트)
