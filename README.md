# CNIE
## 시뮬레이션 뷰어 (그리드 이동 시각화)

```bash
python -m viewer.server          # 브라우저에서 http://127.0.0.1:8765
```

- 배정 정책(BL1~BL6, Greedy-R, RL 체크포인트), 로봇/워크스테이션 수, λ, 이동 규칙(free/lanes), 충돌 처리(reserve/reactive)를 고르고 실행하면 시뮬레이션을 끝까지 돌린 뒤 재생한다.
- 시나리오 분포(`scenario.py`): 도착 과정(포아송, 피크 NHPP, 주기 NHPP, 묶음/웨이브, 변동성 조절 renewal), SKU 수요(균등, ABC 곡선, Zipf), 저장(무작위, 클래스 기반), 피킹/WS 처리 시간(고정, 균등, 지수, 로그정규). 프리셋으로 혼잡 시나리오를 바로 고를 수 있다.
- 재생 화면: 로봇 상태(이동/대기/피킹/WS 처리/주차), 예약 경로, 미배정·배정 주문, 점유/대기 히트맵, 시간대별 지표. RL이면 결정마다 후보별 Q값·Δd·한계비용과 BL6 선택을 함께 보여준다.
- `Export replay`는 실행 하나를 HTML 파일 하나로 내려받는다. 파이썬 없이 브라우저로 열 수 있다 (`파일.html#t=900`으로 900초 시점부터).
- 학습 체크포인트: `python run.py ... --grid [--scenario '{"arrival": "batch", "batch_mean": 6}']`로 학습하면 결과 폴더에 `agent*.pt`가 학습 조건과 함께 저장되고, 뷰어가 저장소 안의 `*.pt`를 목록으로 보여준다.
